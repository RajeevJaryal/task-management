# 🚀 TeamFlow Task Management

A full-stack **Task Management Web App** built with **React, Tailwind CSS, Redux Toolkit, and Firebase**.  
It supports authentication, role-based dashboards, and complete task management with real-time database.

---

## ✨ Features

- 🔐 **Authentication**
  - Email/Password Login & Signup
  - Firebase Authentication

- 👤 **Role-Based Access**
  - Select role after login (Admin / User)
  - Separate dashboards

- 📊 **Dashboard**
  - Admin Dashboard
  - User Dashboard

- ✅ **Task Management**
  - Create Task  
  - View Tasks  
  - Edit Task  
  - Delete Task  
  - Update Task Status  

- 🔄 **State Management**
  - Redux Toolkit for global state

- ☁️ **Backend**
  - Firebase Authentication
  - Firestore (CRUD operations)

---

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS  
- **State Management:** Redux Toolkit  
- **Backend:** Firebase (Auth + Firestore)
